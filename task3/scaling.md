## Масштабирование баз данных

Опишем стратегии масштабирования

| Сервис | Тип базы данных | Стратегия масштабирования |
| ---- | ---- | ---- |
| Сервис ставок | Реляционная | Нужны read реплики: участники аукциона делают ставки, сервис ставок их читает (частая запись, частое чтение) |
| Сервис кампаний | NoSQL | Кампании изменяются не частно, здесь масштабирование не нужно |
| Сервис статистики | Kafka + OLAP | Кафку можно партицировать (по id события), ClickHouse можно шардировать (по id события) |
| Сервис аналитики | OLAP | ClickHouse можно шардировать по id события |
| Сервис финансов | Реляционная | Можно шардировать по клиентам. Транзакции можно партицировать по времени (например, по месяцам) |
