## Кэширование

Опишем стратегии кэширования. Для кэширования используем Redis cluster, кэш храним в оперативной памяти подов.

### Сервис ставок
* Нельзя использовать неактуальные ставки. Ставки могут меняться часто. Поэтому для кэша ставок стоит использовать короткий TTL + инвалидация по событию. 
* До определённого количества рекламодателей (например, 1000) для прогрева кэша можно выгружать все ставки из базы в кэш.

### Сервис кампаний
* Кампании меняются не так часто, поэтому для Ad Server можно настроить для кэша средний TTL + инвалидацию по событию. 
* При старте приложения их можно все выгрузить из базы.

### Сервис финансов
* Кэширование не нужно, тк примерно одинаково операций на запись и чтение.
