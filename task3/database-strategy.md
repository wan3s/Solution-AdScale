## Database per Service

Стратегии данных для каждого сервиса

| Сервис | Тип базы данных | Обоснование |
| ---- | ---- | ---- |
| Сервис ставок | Реляционная | Структура данных четкая и стабильная, важны ACID транзакции |
| Сервис кампаний | NoSQL | Структура данных может меняться + у разных кампаний может быть разный набор полей |
| Сервис статистики | Kafka + OLAP | Потребляет события (просмотры, клики) и вставляет в OLAP (ClickHouse, например)|
| Сервис аналитики | OLAP | Нужно считать агрегации |
| Сервис финансов | Реляционная | Важны ACID транзакции |
