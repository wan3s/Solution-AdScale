## API Gateway для DSP-интеграции

**Маршрутризация**: при получении запроса на показ рекламы, API Gateway роутит запрос в Ad Server.
**Rate Limiting**:
    1. 100 запросов в минуту на пользователя (по JWT claims) — защищает от brute force.
    2. 50 запросов в минуту для неаутентифицированных запросов по IP — защищает от DDoS-атак.
**Circuit Breaker**: размыкатель будет встроен в API Gateway. Если один из DSP перестал успешно отвечать, то перастаем в него ходить, чтобы каскадно не положить все приложение. Размыкатель также будет работать и в обратную сторону: если наше приложение перестаёт справляться, то API Gateway размыкает поход в Ad Server для некоторых DSP партнеров. Так мы получим штрафы от только от этих партнёров, а не от всех сразу из-за упавшего приложения.
