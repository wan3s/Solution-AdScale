## API Gateway для DSP-интеграции

**Маршрутризация**: при получении запроса на показ рекламы, API Gateway роутит запрос в Ad Server.
**Rate Limiting**:
    1. 100 запросов в минуту на пользователя (по JWT claims) — защищает от brute force.
    3. 50 запросов в минуту для неаутентифицированных запросов по IP — защищает от DDoS-атак.
**Circuit Breaker**: если один из DSP перестал успешно отвечать, то перастаем в него ходить, чтобы каскадно не положить весь сервис
